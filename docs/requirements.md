# 需求结构与验收

## 已找回的项目约束
- 独立镜室圆度补偿项目，不引用其他产品的变形结论。
- 0°–359° 每 1° 共 360 点，0°基准边=+X，90°=+Y。
- 报告图片尺寸/版式不固定；绿色实测曲线、红色零线，最终识别纵轴量程。
- 支持人工/Excel数据；最终 Windows 独立 EXE。
- Z 向等截面直圆柱入子；单向去料或双向模式。
- 首版 CSV/DXF 手动导入 UG10.0，后续再联动。

## v0.1 完成范围
严格 CSV → 校验完整性/单位 → 按固定基准去均值 → 候选逆向补偿 → 极坐标转 XYZ → CSV/DXF/审计报告。
不自动插补缺点，不猜测图片量程，不拟合圆心，不去除一次谐波，不平滑、不自动选择加工方向。

验收：合成 ±20μm 椭圆，gain=0.5 时双向补偿 ±10μm；减小半径单向补偿 -20..0μm；CSV 360 点、DXF 360 顶点且闭合；乱序输入排序；重复/缺点/非有限数值/越界拒绝。

## 后续可执行任务
1. 真实报告数据验证：确认径向还是直径误差、报告圆心/滤波、角度注册、测量重复性，记录输入到输出的验收案例。
2. 图片识别适配器：刻度标定、红色零线/绿色曲线分离、360采样、识别置信度和人工修正；低置信度阻止导出。
3. UG10.0接口现场验证：毫米、基准、Z高度、闭合轮廓、折线误差；制定样条拟合公差和实体修改流程。
4. GUI与Excel适配：预览实测/补偿叠图，独立配置每个项目，确认后导出。
5. Windows EXE：冻结依赖、打包、无Python环境验收。

## 尚需工程证据
实际名义半径、基准定位、误差定义、入子为芯子外圆或型腔内圆、模具到产品的响应方向/系数、允许最大去料量及尺寸变化。缺少这些不妨碍合成流程验收，但当前轮廓不能视为已验证加工方案。
